# Phoenix Fall Google Play package

This folder is the submission package for the official Android release of Phoenix Fall.

Package name: `com.phoenix.fall`
App title: Phoenix Fall
Developer contact: hello@phoenixwebsites.ai
Release model: Free, supported by ads and optional in-app purchases

## Files

- `LISTING.md`: store title, descriptions, categorization, and graphic asset requirements.
- `PRODUCTS.md`: exact Google Play product and subscription IDs to create.
- `PRIVACY-POLICY.md`: public privacy policy text. Publish it at a stable public URL before submission.
- `ACCOUNT-DELETION.md`: public account deletion instructions. Publish it at a stable public URL before submission.
- `DATA-SAFETY.md`: answer map for the Play Console Data safety form. Verify the Google Mobile Ads SDK entries against Google's current SDK disclosure during submission.
- `CONTENT-RATING.md`: questionnaire prep and target audience notes.
- `RELEASE-CHECKLIST.md`: technical and policy gates that must pass before production.
- `TESTING.md`: closed test plan and the exact cases verified locally on October 25, 2026.
- `CARTER-TODO.md`: Carter's ordered manual steps. Nothing in this list can be completed by Muse because it requires Carter's accounts, identity, payment, or secret dashboards.
- `assets/play-icon-512.png`: 512 by 512 Play Store icon generated from the app icon source.
